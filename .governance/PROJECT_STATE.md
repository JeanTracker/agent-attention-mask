- 원인은 훅 유출이 아니라 `HOOK_STALL`이 대기 상태에도 적용된 것. 만료 후 휴리스틱으로 되돌아가 `← 2 agents` 푸터 리페인트를 작업으로 오판했다 (D-030).
- 수정: 대기 상태는 만료 없음 + 이벤트 세션 토큰 검증 + 죽은 FIFO 청소.
- 검증: 러너 2개 동시 실행에서 상호 간섭 없음 확인.
