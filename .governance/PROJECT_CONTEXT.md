# PROJECT CONTEXT

## 1. WHY (배경 및 존재 이유)
AI 코딩 에이전트(Claude Code, Antigravity, Codex 등)가 장시간 자율 작업을 수행할 때, 터미널에 쏟아지는 방대한 양의 중간 로그, diff, 디버그 메시지는 개발자에게 시각적 피로와 산만함을 유발한다. 개발자는 작업 중에는 번잡한 출력을 보지 않고 감성적이고 깔끔한 화면(cmatrix 디지털 비)을 감상하다가, 필요할 때 즉시 원래 터미널 화면으로 복귀하여 결과를 확인하길 원한다.

## 2. WHO (타깃 사용자)
iTerm2 및 macOS 터미널 환경에서 AI 에이전트를 가동하는 개발자.

## 3. CORE VALUE (핵심 가치)
- 무간섭 시각적 은닉: 작업 중 터미널 화면을 매트릭스 화면보호기로 우아하게 가림.
- 즉각적 인터랙션 복구: 사용자가 임의의 키/마우스 입력 시 또는 에이전트가 확인을 요청할 때 0.1초 만에 일반 터미널로 복구.
- 완전한 히스토리 보존: 복구 후 마우스 스크롤 시 에이전트의 작업 로그는 100% 보존되면서 cmatrix 잔상은 0줄로 유지.
