# SUCCESS CRITERIA

## 성공 판정 기준
1. **[SC-001] 단일 창 무결성**: 별도의 iTerm2 창이나 분할 패널을 생성하지 않고, 기존 단일 창 내에서 전환된다.
2. **[SC-002] 수동 깨우기 (Manual Wake-up)**: cmatrix 실행 중 임의의 키(스페이스바, 엔터 등) 입력 또는 마우스 클릭 시 0.2초 이내에 에이전트 화면으로 복귀한다.
3. **[SC-003] 자동 깨우기 (Auto Wake-up)**: 에이전트 프로세스가 종료되거나, 사용자 확인(y/n 또는 프롬프트)을 요구하는 유휴 상태가 감지되면 사람의 개입 없이 자동으로 일반 화면으로 복귀한다.
4. **[SC-004] 스크롤백 무오염 (Zero Artifacts)**: 복귀 후 터미널을 위로 스크롤했을 때 cmatrix 잔상이 0줄이며, 에이전트가 출력한 전체 로그가 빠짐없이 스크롤백에 누적되어 있다.
5. **[SC-005] 에이전트 TTY 호환성**: 에이전트는 자신을 TTY 환경으로 인식하여 ANSI 컬러 및 대화형 입력 처리가 정상 동작한다.
