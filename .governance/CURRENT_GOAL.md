# CURRENT GOAL

## G-001: PTY 기반 단일 터미널 Screensaver Runner (amask) 핵심 엔진 구현
임의의 에이전트 명령어를 인자로 받아 실행하되, 다음 라이프사이클을 완벽히 수행하는 CLI 래퍼를 구축한다.

1. 에이전트 명령어를 가상 PTY(Pseudo-Terminal) 하위 프로세스로 실행.
2. **에이전트가 사용자 개입 없이 일정 시간 작업 중일 때** iTerm2 화면을 대체 화면 버퍼(Alternate Screen Buffer)로 전환하고 cmatrix 애니메이션 렌더링. 기동 즉시 전환하지 않는다.
3. 에이전트가 생성하는 모든 출력(stdout/stderr)은 메모리 버퍼에 유실 없이 실시간 누적.
4. 사용자 입력(아무 키 또는 마우스 클릭) 발생 시 즉시 대체 화면을 닫고 가상 PTY로 입출력 패스스루 전환.
5. 에이전트의 완료 또는 입력 대기(Prompt) 상태 감지 시 자동으로 대체 화면을 닫고 누적 로그를 일반 화면에 플러시하여 복귀.
6. **복귀 이후에도 2~5를 반복한다.** 에이전트가 다시 작업에 들어가면 화면을 다시 덮고, 깨어나면 다시 되돌린다. 세션이 끝날 때까지 순환한다.

### 개정 이력
- 2026-09-07: 2번을 "실행과 동시에"에서 "작업 중일 때"로, 6번(재진입)을 신설. 대화형 에이전트 지원을 위한 사용자 승인 결정이며 HRQ-001·HRQ-002를 종결한다. 상세는 D-011.
